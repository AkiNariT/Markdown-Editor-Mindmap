界面回归实际启动打包后的 MD.app，使用隔离测试文档和配置：

- Finder 冷启动、运行中打开文件、已打开文档复用。
- 原生菜单命令派发、中英文切换、Mac 设置指引及 Windows 专属入口隐藏。
- 页面 Command+N/W/S、源码编辑保存、文档与普通命名输入框各自的撤销/重做。
- 经界面重命名真实文件，检查旧路径消失、内容不变、标签更新。
- Finder 打开 `.mdmap`，双击相对路径关联节点复用 Markdown 标签。
- 关闭隐藏后恢复文档与草稿，取消退出后可继续操作；再次退出选择放弃时，原始文件保持上次保存内容。

文件测试覆盖中文路径、大小写改名、已有目标和外部修改保护、并发目标竞争、大小写敏感文件区分、路径别名、独立硬链接，以及只移动符号链接目录项时不误改其真实目标和其他引用。导图的当前数据及撤销/重做记录均有对应回归。

打包检查验证应用身份、版本、最低系统声明、文档类型、图标、主程序/框架/辅助程序架构及 Electron fuses。原始应用、ZIP 解压出的应用和 DMG 内应用均执行递归严格 ad-hoc 签名验证；DMG 检查镜像完整性与 Applications 快捷入口。ZIP 解压保留执行权限和符号链接。

[同一源码的 Windows 发布启动回归 40256168524](https://github.com/AkiNariT/Markdown-Editor-Mindmap/actions/runs/40256168524) 成功，覆盖文件夹版和单文件版在正常及带干扰环境变量时的启动。本地 Windows 11 也执行了最终重命名界面回归：草稿命名、保存、磁盘改名、冲突保护、撤销、位置、缩放、图片与窄窗口均通过。Mac 专属的最后符号链接修复由上述 Mac 原生任务验证。

## 验证边界

- 最低要求为 macOS 13，但本次原生运行环境只有 macOS 15.7.9。没有声称已实测 macOS 13、14 或其他系统与个人设备。
- Playwright 的键盘事件注入页面。系统级 `⌘Q` 未自动化实测；测试确认原生菜单存在标准 `quit` 角色，并直接调用真实 `app.quit()` 验证保存保护、取消和确认退出。Dock 返回通过应用 `activate` 事件验证，未模拟物理点击 Dock。
- 已查看 Mac 中英文设置及导图截图。没有完成个人 Mac 上的触控板、输入法、外接显示器等人工验收。
- 原生界面测试使用构建目录中的应用。ZIP 与 DMG 的内容和签名已验证，但未人工验收浏览器下载后的隔离标记、拖入 Applications、Gatekeeper 提示和 Finder 默认应用选择。
- 预览应用仅有 ad-hoc 签名，没有 Apple Developer ID 签名或公证；DMG 容器本身未签名。签名完整性通过不等于 Gatekeeper 放行。

安装方式与使用限制见 [Mac 使用说明](MACOS.md)。工作流附件是测试构建；公开发布仍以仓库 Releases 实际附件为准。
