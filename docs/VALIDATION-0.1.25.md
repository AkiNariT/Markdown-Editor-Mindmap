# MD 0.1.25 验证记录

验证环境：Windows 11 x64（10.0.26100）、Node.js 24.15.0、Electron 44.5.1。

## 改动与诊断范围

- 设置入口分别保留自动注册和打开系统设置的结果，错误详情显示稳定错误代码和有长度限制的纯文本系统输出。
- 注册失败后仍尝试打开通用 Windows 默认应用页；“打开系统设置”和“复制程序路径”也可独立使用。
- 未知失败不再猜测为权限或 PowerShell 问题。缺少组件、缺少 PowerShell、执行超时、明确权限拒绝和注册冲突分别提示。
- Windows PowerShell 显式使用 UTF-8 控制台输出，避免中文路径在错误详情中乱码；切换语言保留操作结果，帮助页版本号同步。
- 当前实际用户、正在运行的 0.1.24 程序及其注册脚本的只读 DryRun 检查成功，没有复现注册冲突。旧版丢弃了底层异常，因此无法追溯用户截图中那一次失败的具体原因。本版改善诊断与恢复流程，不宣称已复现并解决该次未知底层故障。
