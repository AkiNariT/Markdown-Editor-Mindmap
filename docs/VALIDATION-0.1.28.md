- Windows 10/11 x64 是兼容目标，本轮实际桌面验证环境为 Windows 11；没有新增 Windows 10 实机验证。发布包未签名，macOS 尚未提供下载。
- 本轮不是完整性能基准，不能承诺首次稳定在 2 秒内启动。此前 Electron/WebView2 可行性对照见 [实验记录](WEBVIEW2-EXPERIMENT-2026-10-16.md)，其数据不能当作本次最终包的性能成绩。
- 首次准备缓存验证完整文件 SHA-256，后续复用检查完整标记及文件大小；未宣称每次启动都会重新计算所有文件哈希。缓存退出后保留，新版本与修复可能保留旧副本；个人文档、草稿和设置单独保存。
