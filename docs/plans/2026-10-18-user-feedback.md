# 0.1.29 使用反馈更新

目标：落实用户提供的 0.1.26 实机反馈，保留现有 Markdown 编辑、拖动吸附、多选移动和关联文件行为。

## 已核实与设计

- RunAsNode 开关决定是否接受 ELECTRON_RUN_AS_NODE，并非强制 Node 模式。发布时关闭此能力与 NODE_OPTIONS；当前非 ASAR 包不可开启 OnlyLoadAppFromAsar。分别检查文件夹与单文件产物。
- 导图 v6 添加可选 lineStyle、nodeSize、节点 subtitle、关系线 style/arrow/color；旧 v1–v5 保持可读，不静默丢弃新增字段。
- 节点三档宽度，按完整标题和备注计算高度；所有布局、避障、吸附和导出使用相同尺寸。保留手动位置，提供可撤销的整图“整理布局”清除偏移。
- 图内直接选择曲线、直角、直线；点击关系线可设置实线/虚线、箭头和固定色卡。
- 导出入口提供 SVG、PNG、PDF，原图比例、16:9、16:10、A4 横向，以及当前可见图或总览加分章。导出不修改当前文档。
- 从 Markdown 标题创建新导图，忽略代码块内假标题，保留原文档，关联现有源文件。
