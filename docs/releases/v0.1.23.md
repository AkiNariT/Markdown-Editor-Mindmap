# Markdown-Editor-Mindmap 0.1.23（Markdown 可视化编辑与思维导图）

Markdown-Editor-Mindmap（简称 MD）是一款极简 Markdown 桌面阅读与编辑器，支持所见即所得、源码与双向对照、多文档、本地草稿恢复，以及关联 Markdown 文件的思维导图。本次 Windows x64 公开预览版加入手动检查更新，并包含此前 0.1.22 本地版本的导图外观改进。

## 本次更新

- **手动检查更新：** 从“更多操作（…）→ 检查更新”或“设置 → 检查更新”打开弹窗，再点击检查，读取官方仓库的公开发布信息，包括公开预览版。显示当前版本、最新兼容 Windows x64 版本及纯文本更新说明，可在外部浏览器打开已核对的官方发布页。
- **固定配色：** 预设色卡同时设置节点背景与文字，可恢复默认，支持单步撤销重做。
- **六种整图风格：** 经典、圆角、胶囊、树枝、藤蔓、晶体，同时改变节点与树形连线。
- **旧文件兼容：** 仍可打开 v1 至 v4 导图；旧配色保留，便签和双线按经典造型显示。整图风格使用 v5 格式，最低读取版本仍为 MD 0.1.22。

检查更新不会在后台自动进行，也不会自动下载、安装或重启。关闭弹窗后可继续编辑和保存文档。手动检查连接 `api.github.com`，GitHub 可接收 IP 地址及正常请求元数据；不会发送文档内容、本地路径、草稿或账户令牌。文档远程图片的既有网络行为保持不变。

## 下载与升级

- **[MD-Windows-x64-0.1.23.zip](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.23/MD-Windows-x64-0.1.23.zip)**：普通用户下载，完整解压后运行 `MD.exe`。
- **[MD-source-0.1.23.zip](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.23/MD-source-0.1.23.zip)**：对应版本标签的源码，需要安装依赖并构建。
- **SKILL.md / SKILL.en.md**：独立的中英文 SKILL 模板。
- **SHA256SUMS.txt**：下载文件的 SHA256 校验值。

将新版完整解压到独立目录，保留全部运行时文件；不要只复制 EXE。保存需要保留的修改并正常退出旧版，再打开新版 `MD.exe`，同一用户配置只运行一个实例。若使用 Windows 文件关联脚本，先取消旧目录的注册，再注册新目录。

使用整图风格保存的 v5 `.mdmap` 需要 MD 0.1.22 或更新版本，0.1.21 无法读取。分享导图时请同时提供关联的 Markdown 文件，并保留相对目录结构。
