# Markdown-Editor-Mindmap 0.1.29（Markdown 可视化编辑与思维导图）

根据首轮使用反馈改进的 Windows x64 公开预览版。

## 本次更新

- 导图连线可选曲线、直角、直线；关系线可设置实线／虚线、箭头与固定颜色。
- 节点提供三档宽度，完整显示长标题并随文字增高；新增多行备注。
- “整理布局”清除手动偏移并紧凑排列可见分支，保留折叠状态，支持撤销。
- 导出 SVG、PNG、PDF，支持原图比例、16:9、16:10、A4 横向；可导出当前可见图或总览加各章，PDF 合并为多页。
- Markdown 页面新增“标题转导图”，按标题层级创建新导图，保留原文档与标签。
- 加固发布构建的启动行为，避免外部 Node 环境变量改变 GUI 的启动方式；文件夹和单文件包均增加隔离启动检查。

新增导图属性采用 **v6 格式，需要 MD 0.1.29 或更新版本**。旧 v1 至 v5 导图仍可读取。分享导图时仍需一起提供关联的 Markdown 文件并保留相对目录结构；此版不把讲义正文内嵌进导图。

导出使用白色页面与浅色主题。PNG 最多约 1600 万像素、单边 8192 像素；大型导图建议使用矢量格式或拆分章节。完全重叠的节点仍可能影响连线，大型复杂导图仍有路由计算成本。

## English

This Windows x64 public preview responds to the first user feedback:

- Curved, orthogonal and straight map lines; relationship line styles, arrows and fixed colors.
- Three node widths, complete long titles, automatic card height and multiline notes.
- Undoable Arrange clears manual offsets and compacts visible branches while preserving collapsed branches.
- SVG/PNG/PDF export with natural, 16:9, 16:10 or A4 landscape pages; export the visible map or an overview plus chapter pages. PDF combines pages in one file.
- Headings to map creates a new mindmap from Markdown headings without replacing the original document.
- Hardened packaged startup against external Node environment variables, with isolated checks for both distribution formats.

New properties use **map format v6 and require MD 0.1.29 or later**. Existing v1 through v5 maps still open. Linked Markdown contents are not embedded: include those files and preserve their relative directory structure when sharing a map. Exports use a light theme on white pages; PNG output is limited to about 16 million pixels and 8192 pixels per edge. Very large maps may need vector output or smaller chapters.

Download the recommended **MD-Windows-x64-0.1.29.exe** above and double-click it. Copying or renaming it is supported. The complete folder ZIP remains available; its internal `MD.exe` requires all accompanying files. The six assets provide both builds, tagged source, two templates and checksums.

Save your work and close the old version normally before upgrading. Extract folder builds to a separate directory. Settings and drafts stay in `%APPDATA%\MD` and do not travel with a copied EXE. Repeat default-app setup after changing the executable path. Updates remain manual, with no automatic download, installation or restart.

The approximately **338 MB** single-file app prepares a runtime cache under `%LOCALAPPDATA%\MD\Runtime` on first launch and reuses it afterward. Older copies may remain after updates or repairs; close all MD instances before clearing this cache. First launch within two seconds is not guaranteed. Large maps and fully overlapping cards retain routing limitations.

This unsigned preview targets Windows 10/11 x64. Actual native validation uses Windows 11 x64; a separate Windows 10 machine has not been tested. See the linked validation record for actual checks. Source remains MIT licensed, with third-party notices included. This project is developed primarily with AI tools. A macOS version is planned; no Mac download or confirmed release date is available.
