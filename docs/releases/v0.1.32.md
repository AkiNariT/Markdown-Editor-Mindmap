# Markdown-Editor-Mindmap 0.1.32（Markdown 可视化编辑与思维导图）

Windows x64 公开预览版：在 Markdown 编辑时直接粘贴截图、拖入图片，草稿可以先插图再保存。

## 本次更新

- 在“编辑”模式中按 **Ctrl+V** 粘贴截图或复制的图片，也可拖入图片文件；保留原有“图片”按钮，支持正文、源码与对照视图。
- 新文档无需先保存。草稿图片暂存在本机，首次保存后，引用的图片自动复制到文档旁的 `文档名.assets` 文件夹，并使用相对路径。取消保存保留草稿图片。
- 支持 **PNG、JPEG、GIF、WebP**；一次最多 **10 张**、单张不超过 **20 MiB**、合计不超过 **50 MiB**。一批图片可以一起撤销、重做。
- 图片保存在本机，不上传到 GitHub 或其他服务器。Markdown 保存的是图片引用，分享或移动时请同时提供 `.md` 文件与对应的 `.assets` 文件夹。

阅读模式、文件名输入框与思维导图不会自动插入图片。正文代码块中请先移出光标再插图。操作说明见 [图片粘贴与拖入](https://github.com/AkiNariT/Markdown-Editor-Mindmap/blob/v0.1.32/docs/IMAGE-PASTE.md)。

升级前请保存修改并正常退出旧版，再运行新版。文件夹版解压到独立目录。设置与草稿仍保存在 `%APPDATA%\MD`，复制程序不会自动带走这些数据；文档与图片请保存在自己的文件夹。移动、改名或升级到新路径后，请从新位置重新设置默认应用，并在 Windows 中确认。

单文件版无需安装、管理员权限或启动时下载运行环境。首次启动准备本机运行缓存，后续复用完整缓存；启动时间取决于磁盘和系统负载，不承诺首次启动在 2 秒内完成。更新检查仍由用户手动触发，不自动下载、安装或重启。

## English

This Windows x64 public preview adds **Ctrl+V screenshot/image paste and image-file drop** in Markdown Edit mode. The Image button remains available, and Document, Source and Split views are supported.

Drafts can contain images before their first save. Images stay in local draft storage; saving copies referenced images to the adjacent `document-name.assets` folder and writes relative paths. Canceling Save preserves draft images. A batch is one undo/redo step.

Supported formats are **PNG, JPEG, GIF and WebP**: up to **10 images per import**, **20 MiB per image** and **50 MiB per batch**. Images are not uploaded to GitHub or other servers. Share or move the Markdown file together with its `.assets` folder. Reading mode, filename fields and mindmaps do not insert pasted images; move the caret out of a formatted code block before inserting one.

Choose the single-file EXE above, or extract the entire folder ZIP. The six assets provide both builds, tagged source, two templates and checksums. **Save your work and close the old version normally before upgrading.** Settings and drafts remain in `%APPDATA%\MD`; copying the executable does not transfer them. Repeat default-app setup after changing the executable path. Updates remain manual, and first launch within two seconds is not guaranteed.

This unsigned preview was tested on **Windows 11 x64**. Windows 10 x64 is a compatibility target but has not been tested on a separate device. See the linked validation record for actual checks and limitations. **Mac downloads are unchanged:** the separate [0.1.31 macOS preview](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/tag/v0.1.31) has not been tested on Mac hardware. This project is developed primarily with AI tools. Source remains MIT licensed, with third-party notices included.
