# Markdown-Editor-Mindmap 0.1.28（Markdown 可视化编辑与思维导图）

0.1.28 是 Windows x64 公开预览版，新增思维导图拖动对齐参考线与多选移动，并包含此前 0.1.27 本地版本的启动缓存、内存和连线优化。0.1.27 未单独公开发布。

## 本次更新

- **拖动对齐：** 编辑导图时，拖动节点接近其他可见静止节点所在行或列，会显示蓝色虚线并吸附。拖远脱离，按住 Alt 暂停吸附；松手或取消后参考线消失，不会保存为关系线。吸附距离按屏幕像素计算，缩放后保持一致。此操作替代 0.1.27 本地版的横向、纵向对齐按钮。
- **多选移动：** Ctrl／Shift 点击多个节点，松开修改键后拖动任一选中节点，整组保持相对位置，并以鼠标抓住的节点作为对齐基准。父子同时选中不会重复移动后代；一次拖动提交一个可撤销操作，支持重做与保存。
- **连线与布局：** 实线分支和虚线关系绕开中间节点，说明跟随实际线路。修复负偏移导图的布局原点反复移动及恢复画布位置后右键菜单意外关闭的问题。
- **运行缓存：** 单文件 EXE 首次启动在 `%LOCALAPPDATA%\MD\Runtime` 准备运行文件，后续复用完整缓存，复制或改名 EXE 也可复用。缺失、截断或明确启动失败时准备新副本，旧副本保留，避免打断其他运行中的实例。
- **内存与打包：** Windows 使用软件合成；后台 Markdown 标签卸载编辑器视图以减少内存占用，仍保留文档、撤销记录和阅读位置。修复另存为后的语言事件订阅残留。单文件直接内嵌未压缩运行文件，省去首次启动的中间 ZIP；保留中英文 Chromium 资源、完整 Unicode 数据和第三方许可。

单文件约 **337 MB**，以较大的下载体积减少首次准备步骤。启动时间仍取决于磁盘与系统负载，**不承诺首次启动在 2 秒内完成**。导图对齐不会自动重排整张图；完全重叠的节点可能没有可用连线出口，大型复杂导图仍有路由计算成本。

## 下载与升级

- **推荐：[MD-Windows-x64-0.1.28.exe](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.28/MD-Windows-x64-0.1.28.exe)**：单文件便携版，放到桌面或常用位置后双击即可，也可以改名。无需安装、管理员权限或启动时下载运行环境。
- **[MD-Windows-x64-0.1.28.zip](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.28/MD-Windows-x64-0.1.28.zip)**：完整文件夹版。解压整个 ZIP 后运行 `MD.exe`，保留同目录的 DLL、resources 等配套文件；其中的 `MD.exe` 不能单独复制。
- **[MD-source-0.1.28.zip](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.28/MD-source-0.1.28.zip)**：对应版本标签的源码，需要安装依赖并构建。
- **[SKILL.md](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.28/SKILL.md)**：独立中文 SKILL 模板。
- **[SKILL.en.md](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.28/SKILL.en.md)**：独立英文 SKILL 模板。
- **[SHA256SUMS.txt](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.28/SHA256SUMS.txt)**：以上五个文件的 SHA256 校验值。

升级前保存需要保留的修改，并正常退出旧版，再打开新版。同一用户配置只运行一个实例。使用文件夹 ZIP 时，将新版完整解压到独立目录。

设置和草稿继续保存在当前 Windows 用户的 `%APPDATA%\MD` 中；复制 EXE 不会带走这些数据，文档仍需保存到自己的文件夹。运行缓存只包含程序文件，不随退出删除；新版本或修复可能使磁盘占用累积。需要清理时，先保存文档并退出所有 MD 实例，再删除 `%LOCALAPPDATA%\MD\Runtime`；之后启动会重新准备运行文件。

若已设置默认应用，移动、改名或升级到新路径后，请从新位置进入“更多操作（…）→ 设置 → 设置默认打开方式”重新登记，并在 Windows 中确认默认应用。注册与“复制程序路径”使用你保存的外层 EXE。

应用继续提供手动检查更新，不会后台检查、自动下载、安装或重启。手动检查连接 `api.github.com`，不发送文档、本地路径、草稿或账户令牌。现有更新检查器通过同版本 ZIP 识别兼容更新，进入发布页后可选择推荐的单文件 EXE。

整图风格仍使用 v5 `.mdmap` 格式，最低读取版本为 MD 0.1.22；旧 v1 至 v4 导图仍可读取。分享导图时请同时提供关联 Markdown 文件，并保留相对目录结构。

**English:** This Windows x64 public preview adds blue alignment guides and snapping while dragging mindmap nodes. Hold Alt to move freely. Ctrl/Shift-click multiple nodes, release the modifier key, then drag the group while preserving relative positions; parent/child selections do not apply movement twice. Moves support undo, redo and saving. Connections route around intervening nodes. Fully overlapping cards and large, complex maps still have routing limitations.

This release includes the unpublished 0.1.27 optimizations. The single-file EXE prepares a runtime cache under `%LOCALAPPDATA%\MD\Runtime` on first launch and reuses it afterward, including after copying or renaming the EXE. Missing, truncated or explicitly failed runtimes trigger a new copy without deleting older copies that may still be in use. Inactive Markdown tabs unload editor views to reduce memory use while preserving document state, undo history and reading positions.

Download **MD-Windows-x64-0.1.28.exe** and double-click it; no installation, administrator access or runtime download is required. The approximately **337 MB** EXE embeds uncompressed runtime files to reduce preparation steps. First launch within two seconds is not guaranteed. The complete folder ZIP remains available; its internal `MD.exe` needs all accompanying files. The six assets above provide both builds, tagged source, two templates and checksums.

Save and close the old version normally before upgrading. Settings and drafts remain in `%APPDATA%\MD` and do not travel with a copied EXE. Runtime caches persist after exit and may accumulate across versions or repairs; close every MD instance before clearing `%LOCALAPPDATA%\MD\Runtime`. Repeat default-app setup after moving, renaming or upgrading to a new executable path. Updates remain manual. Map format v5 still requires MD 0.1.22 or later.

This unsigned preview targets Windows 10/11 x64; actual native validation uses Windows 11 x64. See the linked validation record for checks and limitations. Source remains MIT licensed, with third-party notices included. This project is developed primarily with AI tools. A macOS version is planned; no Mac download or confirmed release date is available.
