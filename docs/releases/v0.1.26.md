# Markdown-Editor-Mindmap 0.1.26（Markdown 可视化编辑与思维导图）

Markdown-Editor-Mindmap（简称 MD）是一款极简 Markdown 桌面阅读与编辑器，支持所见即所得、源码与双向对照、多文档、本地草稿恢复，以及关联 Markdown 文件的思维导图。此版本新增单文件便携包：复制一个 EXE 到桌面，就能双击使用。

## 本次更新

- **单文件运行：** `MD-Windows-x64-0.1.26.exe` 包含完整运行资源，可以复制到桌面、其他文件夹或改名后运行，无需安装、管理员权限或额外下载运行环境。
- **启动提示：** 每次启动会在本机临时目录准备运行文件，显示“正在打开 MD / Opening MD”，主程序就绪后提示关闭。等待时间取决于磁盘和系统负载；本机验证曾观察到约 9–29 秒，不代表所有设备的启动速度。
- **路径与默认应用：** 单文件版的默认应用注册和“复制程序路径”使用你保存的外层 EXE。中文、空格路径、改名后的启动，以及已有窗口接收打开请求均纳入本次验证。
- **保留原有数据：** 设置与草稿继续使用当前 Windows 用户的数据目录；复制 EXE 不会复制个人数据。完整文件夹 ZIP 仍提供下载。

## 下载与升级

- **推荐：[MD-Windows-x64-0.1.26.exe](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.26/MD-Windows-x64-0.1.26.exe)**：普通用户选择此文件，放到桌面或其他常用位置后双击即可。
- **[MD-Windows-x64-0.1.26.zip](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.26/MD-Windows-x64-0.1.26.zip)**：完整文件夹版。解压整个 ZIP 后运行其中的 `MD.exe`，需要保留同目录的 DLL、resources 等配套文件；ZIP 内的 `MD.exe` 不能单独复制。
- **[MD-source-0.1.26.zip](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.26/MD-source-0.1.26.zip)**：对应版本标签的源码，需要安装依赖并构建。
- **[SKILL.md](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.26/SKILL.md)**：独立中文 SKILL 模板。
- **[SKILL.en.md](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.26/SKILL.en.md)**：独立英文 SKILL 模板。
- **[SHA256SUMS.txt](https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/download/v0.1.26/SHA256SUMS.txt)**：以上五个文件的 SHA256 校验值。

升级前保存需要保留的修改，并正常退出旧版，再打开新版。同一用户配置只运行一个实例。使用文件夹 ZIP 时，将新版完整解压到独立目录。

设置和草稿保存在当前 Windows 用户的 `%APPDATA%\MD` 中；复制程序到另一台电脑不会带走这些数据。文档仍需保存到自己的文件夹。若已设置默认应用，移动、改名或升级到新路径后，请从新位置进入“更多操作（…）→ 设置 → 设置默认打开方式”重新登记，并在 Windows 中确认默认应用。默认值仍由 Windows 界面确认。

应用继续提供手动检查更新，不会后台检查、自动下载、安装或重启。手动检查连接 `api.github.com`，不发送文档、本地路径、草稿或账户令牌。现有更新检查器通过同版本 ZIP 识别兼容更新，进入发布页后可选择推荐的单文件 EXE。

整图风格仍使用 v5 `.mdmap` 格式，最低读取版本为 MD 0.1.22；旧 v1 至 v4 导图仍可读取。分享导图时请同时提供关联 Markdown 文件，并保留相对目录结构。

**English:** This Windows x64 public preview adds a single-file portable EXE. Download **MD-Windows-x64-0.1.26.exe**, copy it to your Desktop or another folder, and double-click it; renaming is supported. No installation, administrator access or additional runtime download is required. Please wait while “Opening MD” is shown. Runtime files are prepared locally at each launch; observed starts of about 9–29 seconds on the test machine are not a performance guarantee.

The complete folder ZIP remains available. Its internal MD.exe needs all accompanying files and cannot be copied on its own. Save and close the old version normally before upgrading. Settings and draft backups stay in the current Windows user's `%APPDATA%\MD` directory and do not travel with a copied EXE. Repeat default-app setup after moving, renaming or upgrading to a new executable path; Windows confirms the default selection. Updates remain manual, without automatic downloads or installation.

The six downloads above provide the single-file EXE, folder ZIP, tagged source ZIP, two standalone SKILL templates and checksums. This unsigned preview targets Windows 10/11 x64; actual native validation uses Windows 11 x64. See the validation record for the checks performed. Source remains MIT licensed, with third-party notices included. This project is developed primarily with AI tools. A macOS version is planned; no Mac download or confirmed release date is available.
