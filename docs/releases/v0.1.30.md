# Markdown-Editor-Mindmap 0.1.30（Markdown 可视化编辑与思维导图）

修复导图拖动与直角连线的 Windows x64 公开预览版。

## 本次更新

- 主节点、分支和多选组可以越过原画布左边、上边继续拖动，画布自动扩展；子节点继续跟随，支持撤销、重做与保存。
- 拖动补偿兼顾折叠后的小图及显示缩放。忽略未按下鼠标键的悬停事件，避免被误当作拖动而跳位。
- 同列节点的直角分支在无障碍的列间通道采用统一转折位置，修复竖线错位；遇到节点时仍保留绕行。画布与 SVG／PNG／PDF 导出共用修正后的路由。

本次不改变导图格式，**v6 的最低读取版本仍为 MD 0.1.29**，旧 v1 至 v5 导图仍可读取。分享导图时请一并提供关联的 Markdown 文件并保留相对目录结构；若资料在 ZIP 中，请先完整解压后再打开导图。导图不内嵌关联文件正文。

升级前先保存修改并正常退出旧版，再运行新版。文件夹版请解压到独立目录，同一用户配置只运行一个实例。设置与草稿仍在 `%APPDATA%\MD`，不会随 EXE 复制；文档请保存在自己的文件夹。移动、改名或升级到新路径后，请从新位置重新设置默认应用，并在 Windows 中确认。

单文件约 **338 MB**，无需安装、管理员权限或启动时下载运行环境。首次启动在 `%LOCALAPPDATA%\MD\Runtime` 准备运行缓存，后续复用完整缓存；更新或修复可能保留旧副本。清理缓存前须保存文档并退出所有 MD 实例。启动时间取决于磁盘和系统负载，不承诺首次启动在 2 秒内完成。

更新检查继续由用户手动触发，只读取官方 GitHub 发布信息，不发送文档、路径或草稿，也不自动下载、安装或重启。

## 验证、许可与计划

本版为未签名的便携预览版，不含安装器。Windows 10／11 x64 是兼容目标；实际原生桌面验证使用 Windows 11 x64，尚未在独立 Windows 10 机器验证。检查与限制见 [0.1.30 验证记录](https://github.com/AkiNariT/Markdown-Editor-Mindmap/blob/v0.1.30/docs/VALIDATION-0.1.30.md)。完全重叠的节点仍可能遮挡连线，大型复杂导图仍有路由计算成本。

本项目主要借助 AI 工具开发。源码采用 MIT 许可证，第三方许可随软件提供。后续继续优化现有功能并开发 macOS 版本，目前没有 Mac 下载包或确认的发布日期。另见 [项目声明](https://github.com/AkiNariT/Markdown-Editor-Mindmap/blob/v0.1.30/NOTICE.md)、[隐私说明](https://github.com/AkiNariT/Markdown-Editor-Mindmap/blob/v0.1.30/PRIVACY.md) 与 [开发计划](https://github.com/AkiNariT/Markdown-Editor-Mindmap/blob/v0.1.30/ROADMAP.md)。

## English

This Windows x64 public preview fixes mindmap dragging and orthogonal connections:

- Roots, branches and selected groups can move beyond the original top and left canvas edges. The canvas expands, children follow, and undo, redo and saved positions remain supported.
- Drag compensation handles collapsed small maps and display scaling. Mouse movement without a pressed button no longer affects an active drag.
- Orthogonal branches to aligned nodes use a consistent bend when the corridor between columns is clear. Obstacle detours remain available. The canvas and SVG/PNG/PDF exports share the corrected routing.

There is no map format change. **Format v6 still requires MD 0.1.29 or later**, and v1 through v5 maps remain readable. Include linked Markdown files and preserve their relative directory structure when sharing a map. Extract the complete ZIP before opening a map inside it; linked text is not embedded.

Download the recommended **MD-Windows-x64-0.1.30.exe** above and double-click it. Copying or renaming it is supported. The complete folder ZIP requires all accompanying files. Six assets provide both builds, tagged source, two templates and checksums.

Save your work and close the old version normally before upgrading. Extract folder builds to a separate directory. Settings and drafts remain in `%APPDATA%\MD`; copying the EXE does not transfer them. Repeat default-app setup after changing the executable path. Updates remain manual, with no automatic download, installation or restart.

The approximately **338 MB** single-file app prepares a cache under `%LOCALAPPDATA%\MD\Runtime` on first launch and reuses it afterward. No installation, administrator access or runtime download at launch is required. Older cache copies may remain after updates or repairs; close all MD instances before clearing them. First launch within two seconds is not guaranteed.

This unsigned preview targets Windows 10/11 x64. Actual desktop validation uses Windows 11 x64; a separate Windows 10 machine has not been tested. See the linked validation record for checks and limitations. Large maps and fully overlapping cards retain routing limitations. Source remains MIT licensed, with third-party notices included. This project is developed primarily with AI tools. A macOS version is planned; no Mac download or confirmed release date is available.
