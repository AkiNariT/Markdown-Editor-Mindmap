# Markdown-Editor-Mindmap 0.1.25（Markdown 可视化编辑与思维导图）

Markdown-Editor-Mindmap（简称 MD）是一款极简 Markdown 桌面阅读与编辑器，支持所见即所得、源码与双向对照、多文档、本地草稿恢复，以及关联 Markdown 文件的思维导图。本次 Windows x64 公开预览版加入导图草稿流程和 Windows 默认应用设置，并包含此前 0.1.24 本地版本的改进。

## 本次更新

- **先写再保存：** 双击未关联节点立即进入 Markdown 草稿，以节点文字生成标题和建议文件名。写好内容后，首次保存才选择位置、创建文件，并给原节点加上关联星标。重复双击回到同一草稿；取消保存会保留内容，草稿与待关联关系支持本地恢复。
- **保护后续操作：** 原节点已删除、已手动关联其他文件或导图已关闭时，文档仍可保存，但不会强行关联。首次创建不会覆盖已有文件；撤销关联保留已保存文件。退出程序时先处理待关联草稿，再询问是否保存导图的新改动。
- **Windows 默认应用入口：** 从“更多操作（…）→ 设置 → 设置默认打开方式”登记当前便携版和开始菜单入口，随后打开 Windows 设置，由你为 `.md` 和 `.markdown` 选择 MD。此按钮不创建桌面快捷方式。
- **可继续操作的错误提示：** 分别报告注册和打开设置的结果；注册失败后仍尝试打开通用默认应用页。可独立点击“打开系统设置”或“复制程序路径”，在系统文件选择框中找到当前程序。
- **更清楚的诊断：** 区分组件缺失、PowerShell 缺失、超时、权限拒绝、注册冲突和未知错误；未知错误不会被当作权限问题。可展开错误代码与有限长度的纯文本详情，中文路径使用 UTF-8 输出，中英文切换保留当前结果。

默认应用最终由 Windows 界面确认；注册成功或打开设置不代表默认值已经更改。注册、程序路径复制和错误详情都在本机处理，不上传文档或诊断。

将新版完整解压到独立目录，保留全部运行时文件；不要只复制 EXE。保存需要保留的修改并正常退出旧版，再打开新版 `MD.exe`，同一用户配置只运行一个实例。若旧版仍是默认打开程序，请从新版“设置”重新登记当前位置，再在 Windows 中确认默认应用。

应用仍需手动检查更新，不会后台检查、自动下载、安装或重启。手动检查会连接 `api.github.com`；检查不发送文档、本地路径、草稿或账户令牌。

整图风格仍使用 v5 `.mdmap` 格式，最低读取版本为 MD 0.1.22；旧 v1 至 v4 导图仍可读取。分享导图时请同时提供关联 Markdown 文件，并保留相对目录结构。

**English:** This Windows x64 public preview includes the earlier local 0.1.24 improvements. Double-click an unlinked mindmap node to start an editable Markdown draft. Write first, then choose a destination on the first save; only a successful save creates the file, links the node and adds its star. Repeated double-clicks reuse the draft, canceled saves retain content, and pending links survive local recovery. Existing files are protected. Deleted, relinked or closed map targets are not overridden, and undoing a link keeps the saved file.

Settings → Set default app registers the current portable application and a Start Menu entry, then opens Windows Settings. Choose MD for `.md` and `.markdown` there; Windows confirms the selection. Registration and Settings failures now have separate outcomes, precise error codes and plain-text details, with UTF-8 output for Chinese paths. Open Windows Settings and Copy program path provide independent manual recovery. These local actions do not upload documents or diagnostics, and opening Settings does not confirm a default change.

Download the complete portable ZIP, extract it to a separate folder, save and close the previous version normally, then run the new MD.exe. Update default-app registration from the new location if needed. Updates remain manual, with no automatic download, installation or restart. Map format v5 still requires MD 0.1.22 or later. This unsigned preview targets Windows 10/11 x64; actual desktop validation uses Windows 11 x64. See the validation record above for this release's checks. Source remains MIT licensed, with third-party notices included. This project is developed primarily with AI tools. A macOS version is planned; no Mac download or confirmed release date is available.
