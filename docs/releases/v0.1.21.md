# MD 0.1.21 — Markdown 编辑器与思维导图（Windows x64 预览版）

极简 Markdown 桌面阅读与编辑器，支持所见即所得、源码与双向对照、多文档、本地草稿恢复，以及关联 Markdown 文件的思维导图。

## 本次新增

- 虚线连接可添加说明，文字自动避开方块，支持撤销重做。
- 双击未关联节点，选择位置后创建、关联并打开 Markdown。
- 自定义节点背景色，提供经典、圆角、便签、胶囊、双线五种样式。
- 导图 v4 格式保存新属性，保留旧版文件读取能力。

## 下载

- **MD-Windows-x64-0.1.21.zip**：普通用户下载。完整解压后运行 MD.exe。
- **MD-source-0.1.21.zip**：对应版本标签的源码，需要安装依赖并构建。
- **SKILL.md / SKILL.en.md**：独立的中英文 SKILL 模板。
- **SHA256SUMS.txt**：上述文件的 SHA256 校验值。

升级前先保存并退出旧版；不要只复制 EXE。使用新属性保存的 v4 导图需要 0.1.21 或更新版本。撤销新文件关联会保留已创建的磁盘文件。

**English:** First public preview of MD, a minimal Windows Markdown editor with visual/source/split views and linked mindmaps. This release adds relationship labels, double-click file creation, custom node backgrounds and five card styles. Download the Windows x64 portable ZIP, extract the full folder, and run MD.exe. Save and close the previous version before upgrading. New map properties require v4 / MD 0.1.21+. The build is unsigned; Windows 11 was tested, while Windows 10 remains a compatibility target. MIT and third-party notices apply. Checksums and independent SKILL templates are attached.
