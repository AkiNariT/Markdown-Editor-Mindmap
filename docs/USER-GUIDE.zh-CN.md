# MD 功能与快捷键使用手册

适用于基于 0.1.32 的 Windows x64 开发构建，含标题定位、可编辑 ZIP 分享包和文内查找。日常写作按 **Ctrl+S** 保存当前文件。要把导图连同文章和图片交给另一台电脑，打开导图，选 **更多操作 → 导出可编辑分享包…**。

## 第一次使用

1. 完整解压 Windows 程序包，双击文件夹中的 `MD.exe`。保留同目录的 DLL 和 `resources` 文件夹。
2. 按 `Ctrl+O` 打开已有的 `.md`、`.markdown` 或 `.mdmap`，也可以把文件拖进窗口。按 `Ctrl+N` 新建 Markdown，点顶栏「思维导图」新建空白导图。
3. 打开的文档默认可阅读。点右上角「编辑」开始修改，按 `Ctrl+S` 选择保存位置。点顶栏文件名可以提前给草稿起名，首次保存时才写入文件。

## 日常快捷键

| 操作 | Windows 快捷键 | 使用位置或效果 |
| --- | --- | --- |
| 打开 / 新建 Markdown | `Ctrl+O` / `Ctrl+N` | 「打开」可一次选多个文件，各占一个标签 |
| 保存当前文件 | `Ctrl+S` | 在导图标签保存导图，在文章标签保存文章 |
| 另存为 | `Ctrl+Shift+S` | 在可视化正文中选着文字时，建议点「更多操作 → 另存为」，见下节 |
| 切换阅读 / 编辑 | `Ctrl+Shift+E` | 对当前文档或导图生效 |
| 命名 / 重命名文件 | `F2` | 已保存的文件在原目录改名。编辑导图时，画布上的 `F2` 有单独用途 |
| 下一个 / 上一个标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 焦点在标签按钮上时也可按 `→` / `←` |
| 关闭当前标签 | `Ctrl+W` | 有待保存的修改时可选择保存、放弃或取消关闭 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z` | 编辑模式。对照视图按两侧最近的修改顺序撤销 |
| 查找当前 Markdown | `Ctrl+F` | 对照视图查找最近操作的一侧 |
| 放大 / 缩小 | `Ctrl+=` / `Ctrl+-` | 也可用 `Ctrl` 加滚轮，每次调整 10 个百分点，范围 50%～200% |
| 还原到 100% | `Ctrl+0` | 也可点击底部的缩放百分比 |

## 阅读、编辑与查找 Markdown

**选择视图。** 用标签栏右侧的「正文」「源码」「对照」切换。「正文」可以直接编辑排版后的文字。「源码」显示完整 Markdown，适合修改 YAML 文件头、公式或其他特殊语法。「对照」两侧都能编辑，可取消「同步滚动」分别查看不同段落。点左上角「章节目录」可以按标题跳转。

**设置格式。** 在「正文」或「对照」的正文一侧点「编辑」。格式栏可以插入标题、列表、待办、引用、表格、代码块和图片。选中文字可设置链接或删除线，点进表格可增删行列，点进代码块可选择高亮语言。

| 正文编辑快捷键 | 作用 |
| --- | --- |
| `Ctrl+B` / `Ctrl+I` | 粗体 / 斜体 |
| `Ctrl+E` | 行内代码 |
| `Ctrl+Alt+1` 至 `Ctrl+Alt+6` / `Ctrl+Alt+0` | 一至六级标题 / 普通段落 |
| `Ctrl+Shift+7` / `Ctrl+Shift+8` / `Ctrl+Shift+9` | 有序列表 / 无序列表 / 待办列表 |
| `Ctrl+Shift+B` / `Ctrl+Alt+C` | 引用 / 代码块 |
| `Shift+Enter` | 在普通段落内换行，继续同一段落 |
| `Tab` / `Shift+Tab` | 列表项缩进 / 提升一级。在表格中移到下一格 / 上一格，最后一格按 `Tab` 新增一行 |
| `Ctrl` 加单击链接 | 编辑时打开网页或邮件链接。阅读时直接单击 |

当前构建中，选中文字后按 `Ctrl+Shift+S` 可能同时应用删除线并打开「另存为」。要保留选中文字的格式，请从「更多操作」选择「另存为」。对含特殊语法的文章，直接在「源码」中编辑能保留原有标记。可视化编辑可能规范化排版，遇到不支持的语法时，应用会提示另存副本。

**查找文字。** 在阅读或编辑状态按 `Ctrl+F`，或点「更多操作 → 文内查找」。输入文字后可看到当前匹配和总数，例如「2 / 5」。查找框内按 `Enter` 到下一处，`Shift+Enter` 到上一处，到末尾会循环。按 `Esc` 回到查找前的位置和选区。要找 Markdown 标记，请先点「源码」或对照中的源码一侧。

**插入图片。** 在编辑状态按 `Ctrl+V` 粘贴截图，或把图片拖入正文或源码。支持 PNG、JPEG、GIF、WebP，每次最多 10 张，单张最多 20 MiB，合计最多 50 MiB。新文档可以先插图，首次保存后，引用的草稿图片会放进文档旁的同名目录。例如 `讲义.md` 对应 `讲义.assets/`。

## 用导图组织文章

**从现有文章生成。** 先保存 Markdown，再点「标题转导图」。标题层级会变成一张新导图，原文章仍在原标签。双击生成的标题节点，或点节点旁的星标，可回到原文对应小节并看到短暂高亮。同名标题按上级章节和出现顺序区分。用未保存的文章也能生成结构，若需要回跳，请先保存原文再生成。

**从导图开始写。** 选中节点后，点「关联 Markdown」选择一篇已有文章。也可以直接双击未关联的节点，写一篇以节点文字为标题的新草稿。再次双击会回到同一篇，首次保存成功后节点出现星标。手动关联的节点打开整篇文章。

下表的新增、编辑、删除操作均在**导图编辑模式**使用。先单击节点或关系线，让焦点回到画布。

| 按键或手势 | 效果 |
| --- | --- |
| `Tab` / `Enter` | 新增子主题 / 同级主题。根节点只能新增子主题 |
| `F2` | 编辑选中节点的标题，或选中关系线的说明 |
| 标题或关系说明框内 `Enter` / `Esc` | 保留已输入的文字并回到画布。在备注框里，`Enter` 换行，`Esc` 结束输入 |
| `Delete` 或 `Backspace` | 选中单个非根节点时，确认后删除该节点、子树及相关连线。选中自定义关系线时直接删线，可撤销 |
| `Ctrl` 或 `Shift` 加单击节点 | 逐个加入或移出多选。松开修饰键，拖动任一选中节点即可整组移动 |
| 拖节点时按住 `Alt` / 按 `Esc` | 暂停对齐吸附 / 取消本次尚未松手的拖动。拖父节点会带动子树 |
| 拖动画布空白处 | 平移。阅读和编辑模式均可用，点「居中」回到根节点 |

要连起不同分支，右键起点节点，选「建立连接」，再单击目标节点。选中关系线可调线型、箭头和颜色，双击可写说明。选中节点可改外观、宽度或备注，用节点旁的折叠按钮收起子树。「整理布局」会清除全图的手动偏移，可用 `Ctrl+Z` 撤销。

## 保存、导出和换电脑

| 你要做什么 | 从哪里操作 | 得到什么 |
| --- | --- | --- |
| 继续日常编辑 | 当前标签 →「保存」 | Markdown 文件保存文章和图片引用，`.mdmap` 保存导图结构、布局和节点关联。每个文件分别保存 |
| 发给别人继续编辑 | 「更多操作 → 导出可编辑分享包…」 | 一个 ZIP，收录当前文章或导图、节点关联文章及引用的可用本地图片 |
| 发给别人看图或打印 | 导图工具栏 →「导出」 | SVG、PNG 或 PDF，可选「当前可见图」或「总览与各章」。分章 PDF 合为多页，SVG 和 PNG 分文件编号 |

**换电脑操作示例**

1. 在原电脑打开要带走的导图，选「更多操作 → 导出可编辑分享包…」。分享包会取已打开关联文章的最新编辑，也收录从该导图节点新建且仍打开的草稿。导出后仍可回到原文件继续写。
2. 如果弹出「核对分享资源」，检查列出的文件和图片。要离线使用，可取消导出，补齐缺失文件或把外部图片改成本地图片，再导出。「仍然导出」会保留能收集到的资料。正文里的普通文件超链接保留原路径，需要随包发送的其他文章请关联到导图节点。
3. 在另一台电脑**完整解压**项目 ZIP。运行这版 MD，按 `Ctrl+O` 打开解压目录顶层的 `.mdmap`。节点文章在 `documents/`，图片在 `assets/`。如果从单篇文章导出，则打开顶层的 Markdown 文件。

带标题定位的导图使用 **v7 格式**。接收方应使用这份开发构建或其他支持 v7 的版本。公开版 0.1.32 最高读取 v6。本构建也可打开 v1 至 v6 的旧导图。

## 本机恢复与设置

- **草稿与边界。** 底部显示备份状态。重启会恢复最近成功备份的草稿、标签和阅读位置，撤销历史只在本次使用中保留。单份文档上限为 8 MiB，超限草稿保留上次有效备份。缩小文档后可继续保存。换电脑时，导图的节点布局随文件携带，窗口大小、阅读位置和当前缩放属于本机设置。
- **SKILL 模板。** 点顶栏「SKILL 模板」创建新标签，填写「技能名称」和「用途与触发条件」，编辑正文后保存为 `SKILL.md`。
- **外观、语言和默认应用。** 在「更多操作」切换黑色或浅色外观，进入「设置」选择简体中文或 English。要双击 Markdown 时用 MD 打开，点「设置默认打开方式」，再到 Windows 设置中为 `.md` 和 `.markdown` 确认选择 MD。
