Markdown-Editor-Mindmap（Markdown 可视化编辑与思维导图）0.1.23

运行：双击“MD.exe”。便携文件夹里的其他文件请保留在原位。
更新版本时，将新版完整解压到独立目录，保存需要保留的修改并正常退出旧版，再打开新版 MD.exe；同一用户配置只运行一个实例。已有本机恢复记录仍可读取。
适用目标：Windows 10 / Windows 11 的 64 位 x64 系统。这是一份便携构建，不需要安装 Node.js 或开发工具。

检查更新
右上角“更多操作”（…）→ 检查更新，或“设置”→ 检查更新，打开更新弹窗后点击检查。应用读取固定的官方仓库 AkiNariT/Markdown-Editor-Mindmap 的公开 GitHub 发布信息，包括公开预览版，显示当前版本、最新兼容 Windows x64 版本和纯文本更新说明。点击发布页按钮会在外部浏览器打开已核对的官方版本页面，再自行下载便携包。
应用不会在后台自动检查，也不会自动下载、安装或重启。关闭弹窗后可继续编辑和保存；网络不可用或检查失败不影响关闭弹窗后的正常使用。
手动检查会连接 api.github.com，GitHub 可接收 IP 地址和正常请求元数据；不会发送文档、文件路径、草稿或账户令牌。文档中的远程图片仍按原有方式访问图片服务器，浏览器下载属于外部应用的网络行为。详见 PRIVACY.md。
0.1.23 发布页：https://github.com/AkiNariT/Markdown-Editor-Mindmap/releases/tag/v0.1.23

Windows 使用
窗口会记住普通大小、位置与最大化状态；重开时按当前屏幕可用区域校正。系统缩放使用 Electron 的设备独立坐标，文档 Ctrl+滚轮缩放仍单独保留。连续从资源管理器打开文件时会排队处理，重复文件复用已有标签。
需要“打开方式”和快捷方式时，在固定位置解压整个程序目录，再双击 Register-MD.cmd；只为当前用户注册，无需管理员权限。右键 .md、.markdown 或 .mdmap → 打开方式 → MD；要双击直接打开，可在 Windows 的“选择其他应用”中自行设置始终使用 MD。注册脚本不会替换已有默认应用。
Unregister-MD.cmd 删除本目录对应的注册与快捷方式。移动或删除程序前先取消注册，移动或升级到新目录后重新注册。直接双击 MD.exe 始终可以运行。
注册脚本支持 -DryRun 预览；windows-integration.ps1 可阅读具体操作。应用本身不会自动注册文件关联。

语言设置
右上角“更多操作”（…）→ 设置 → 语言，可选简体中文或 English。切换立即生效，重启后保留；已有文档、节点文字和未保存内容保持原样。英文界面新建的欢迎文档与 SKILL 模板使用英文。English guide: README.en.txt。

本次导图更新
连线说明：选中虚线直接输入说明；双击虚线或说明、右键“编辑说明”也可进入。清空说明可移除标签。说明会避开方块与其他说明，必要时以细线指回原连接。
双击创建：未关联节点双击后，以节点名称建议 Markdown 文件名，选择位置后创建、关联并进入编辑；已有文件不会被覆盖。取消不改变节点；撤销关联会保留磁盘文件。
节点外观：编辑模式选中节点后，点击预设色卡即可同时设置背景和文字。可选默认、灰、蓝、绿、紫、粉、橙、棕；默认恢复跟随外观的配色。整图风格提供经典、圆角、胶囊、树枝、藤蔓、晶体，统一改变节点与分支连线，支持撤销、保存和恢复。整图风格使用 v5 格式，需要 MD 0.1.22 或更新版本；v1 至 v4 文件仍可读取，旧配色保留，便签/双线以经典造型显示。

日常使用
草稿恢复：输入后约半秒自动备份，空闲时补存会话状态。底部显示“草稿已备份”或“会话已保留”，备份失败可悬停查看原因。备份不会覆盖原文件，仍需 Ctrl+S 保存。异常退出后恢复最近成功备份的内容；重启恢复标签、阅读/编辑模式、缩放、滚动位置与导图选中节点。撤销历史不会跨重启保留。明确放弃或关闭的草稿不再恢复。
阅读界面：正文和导图在阅读时收起修改控件，编辑时常用控件立即出现。打开文档统一使用顶部“打开”，支持 Markdown 与 .mdmap 思维导图。
恢复记录保存在当前用户的 MD 应用数据目录（可用 --user-data-dir 指定）。每份文档最多 8 MB，最多 80 个标签，恢复文件总计最多 128 MB；超限会显示备份失败。
双击打开：在阅读或编辑状态，双击已关联Markdown的节点文字或卡片空白处，打开对应文件。已有文档复用原标签并保留位置及未保存内容。星星仍可单击打开；已关联节点通过顶部节点输入框或右键“编辑文字”改名，未关联节点双击后可创建并关联 Markdown，文字通过顶部输入框或右键编辑。拖动与建立连接时避免误打开文件。
节点颜色与星标：进入编辑后选中导图节点，使用固定色卡同时设置背景与文字，“默认”恢复跟随浅色/黑色外观。固定配色支持保存、撤销重做，使用至少 v4 格式；整图风格使用 v5 格式。关联 Markdown 的节点仅显示 ★ 标记，点击星星打开文件，悬停查看文件名；未关联节点没有标记或提示。
导图拖动与右键：进入编辑后直接拖动节点卡片，父主题带着子分支一起移动，连线实时跟随；拖动空白处仍是平移画布。一次拖动可以一次撤销，Esc取消尚未放开的拖动。手动偏移会随导图保存，增删或折叠主题仍会按树结构整理基础布局。
节点连接：右键节点→“建立连接”→点击另一个节点，建立额外关系线，不改变父子结构。右键关系线→“删除连接”，也可以选中关系线后按Delete；这些操作均可撤销。右键空白处可针对当前选中主题操作，菜单标明目标。原Markdown关联入口在菜单中单独显示。
导图格式：仍可读取 v1 至 v4 导图；.mdmap 扩展名保持不变。手动位置与关系线需要至少 v2 / MD 0.1.15；旧自定义文字颜色需要至少 v3 / MD 0.1.16；固定配色与连接说明需要至少 v4 / MD 0.1.21；整图风格需要 v5 / MD 0.1.22。旧程序遇到不支持的格式会拒绝打开，防止静默丢失字段。
思维导图：点击顶部“思维导图”，在新标签创建独立导图。选中节点后使用可见的“子主题”“同级主题”和“节点文字”输入框编辑；删除分支需要确认，可撤销/重做。选择“关联 Markdown”指定本地文件，再用“打开文件”进入文档标签，原导图与已打开文档的位置和修改保留。每个节点可关联一个文件。
导图操作：可折叠/展开分支，拖动画布空白处平移，使用 Ctrl+滚轮或底部按钮在 50%～200% 缩放；“居中”返回主题。阅读模式允许选择节点、打开文件，以及双击未关联节点创建 Markdown；其他修改需先点击“编辑”。保存为 .mdmap，点击顶部文件名可命名，“打开”也支持读取导图。编辑时画布上的 F2 编辑当前节点文字或连接说明。
导图链接：保存时尽量使用相对路径，跨盘用绝对路径；另存到其他目录会重新计算链接。保存导图不会保存关联 Markdown 正文。在 MD 内重命名 Markdown 时，打开中的导图会更新对应链接并提示保存；未打开的导图或外部移动/改名无法自动追踪，失效时请重新关联。分享时请保留导图与 Markdown 的相对目录结构，关联文件不会打包进导图。
命名：点击顶部文件名或旁边的铅笔，也可按 F2。新文档可以先命名再写，保存时沿用这个名称；省略扩展名时自动补全 .md。已有文件会在原目录重命名，未保存的正文、撤销记录与阅读位置仍保留。名称无效或已存在同名文件时会提示，不覆盖目标文件。
打开：点击“打开”、按 Ctrl+O，或把 .md/.markdown/.mdmap 文件拖进窗口。“打开”对话框可同时选择多份文档。
多文档：顶栏下方的标签栏切换文档。打开、新建与 SKILL 模板都增加标签，每份文档分别保留阅读位置、未保存内容、阅读/编辑状态与撤销历史。同一文件再次打开会切回已有标签；不同文件夹里的同名文件会分别打开。标签过多时可横向滚动，悬停显示完整路径。
关闭标签：点击标签上的 ×，或按 Ctrl+W；最后一个标签关闭后提供空白文档。Ctrl+Tab 切换到下一个标签，Ctrl+Shift+Tab 切换到上一个。
SKILL 模板：点击顶部“打开”旁边的“SKILL 模板”，在新标签中创建可编辑的模板文档。直接填写上方“技能名称”和“用途与触发条件”，在下方编辑正文，再保存为 SKILL.md。名称使用小写英文、数字与连字符（最多 64 个字符）；用途不能为空（最多 1024 个字符），不能含 < 或 >。原有标签与未保存修改会保留，内置模板可反复使用。
YAML 文件头：合法文件头与正文分开处理。仅修改正文时，原有文件头逐字节保留，不再要求另存副本。SKILL.md 的名称和用途可以用输入框修改，其他字段与注释保留。普通 YAML 文档的自定义字段暂不提供可视化编辑，但会随正文原样保存。
阅读：已有文档默认进入阅读模式，左上角目录图标可以展开章节目录。
文档缩放：按住 Ctrl 滚动鼠标滚轮，上滚放大、下滚缩小，每次调整 10%，范围 50%～200%。底部常驻显示当前比例，也可点 − / + 调整。点击百分比或按 Ctrl+0 恢复 100%；Ctrl++ / Ctrl+− 同样可用。正文、源码和对照均支持，工具栏保持原尺寸。每份文档单独保留比例并在重启后恢复，缩放不修改 Markdown 文件。
显示模式：标签栏右侧的“正文”“源码”“对照”按钮直接切换。正文保留排版阅读与可视化编辑；源码显示完整 Markdown，包含 YAML 文件头、注释和参考链接定义；对照显示源码和实时渲染预览。对照宽窗口左右排列，窄区域上下排列。
源码编辑：在源码或对照模式点击“编辑”，直接修改 Markdown 文本。仅编辑源码时，保留原始标记、BOM、CRLF/LF 和结尾空行。SKILL 字段仍在保存时校验，错误或尚未完成的草稿会留在窗口中。
双向对照：对照模式点击“编辑”后，源码与排版正文都可以修改，并立即互相同步；顶部格式栏可操作正文中的标题、列表、表格、代码块等。SKILL 名称和用途也可直接编辑。Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z）与菜单撤销按最近编辑顺序作用于两侧及字段。切回“阅读”后两侧只读。修改排版正文可能标准化 Markdown 标记；特殊语法经正文编辑后仍需另存副本，撤销回原始源码可恢复完整文本。
行尾：仅查看时，混合换行与仅 CR 换行也原样保留。实际编辑混合换行的文档后，含 CRLF 时统一使用 CRLF；仅 CR 的文档沿用 CR，其余使用 LF。
模式位置：首次进入源码或对照会按当前阅读进度定位，返回已用过的模式会恢复该模式的位置。每个标签分别保留显示模式、源码缓冲区和滚动位置。对照的“同步滚动”按两侧阅读进度联动，可取消勾选独立阅读。
编辑：点击右上角“编辑”时保持当前阅读位置，直接点击正文输入文字，无需修改 Markdown 源码。切回阅读或使用 Ctrl+Shift+E 也保持位置。
标题：编辑模式下，正文上方的“格式”下拉框可直接选择正文和一至六级标题，光标放在段落内即可。
列表：正文上方直接提供无序列表、有序列表和待办按钮；再次点击可取消当前列表格式。
格式：常用格式栏独立位于正文滚动区上方，按钮逐行等宽并占满整行，滚动时保持可见且不覆盖正文；选中文字后仍有浮动工具栏，设置粗体、斜体、删除线和链接。
其他格式：引用、表格、图片、代码块和分隔线均直接显示在编辑栏，与列表按钮使用一致的样式；窄窗口自动换行。
代码块：阅读和编辑时都显示语法高亮。输入时颜色随内容更新；编辑代码块时，编辑栏出现“语言”，可选自动识别、常用语言或纯文本。自动识别可能猜错，手动指定语言更稳定。保存保留语言标记和普通代码文本，颜色不会写入文件。
表格：点击单元格输入；光标在表格中时，底部会出现增删行列按钮。
保存：Ctrl+S。另存为：Ctrl+Shift+S，也可以在右上角“更多操作”菜单选择。
新建：Ctrl+N。撤销：Ctrl+Z。重做：Ctrl+Y。
切换阅读/编辑：Ctrl+Shift+E。黑色外观位于“更多操作”菜单，以纯黑正文底色和深灰分隔呈现。

图片
插入本地图片前先保存文档。支持 PNG、JPEG、GIF、WebP，最大 20 MB。
插入后图片复制到文档旁边的“文档名.assets”文件夹。分享文档时请同时带上该文件夹。
已有文档的相对图片路径以该文档所在目录为基准。
另存到其他目录时，现有图片路径会重新计算，继续引用原图片；不会复制原资源文件夹。
显示远程图片时，会连接该图片所在的服务器。文档内容不会上传。

文件保护与兼容范围
支持 UTF-8 文本（含 BOM），单份文档最大 8 MB；其他编码请先转换。
常用 Markdown、任务列表与简单 GFM 表格已经测试。
未修改时保存会保留原文件文本。编辑后，空行、标记与表格写法可能标准化。
格式有误的 YAML 文件头、HTML、脚注、数学公式、特殊提示块、双向链接等扩展暂不能完整编辑。
检测到这些扩展时会显示提示；允许阅读，编辑后必须另存副本，原文件不覆盖。
上述副本规则适用于正文的可视化编辑。完整源码模式可以直接编辑特殊语法并保存原文件；预览可能不能完整显示这些语法。已经发生有损正文编辑后再切到源码，仍需另存副本。正文编辑撤销回到原源码的渲染状态时，会恢复完整原始源码。
保护检测不能覆盖所有 Markdown 方言。重要文档建议先保留备份或另存副本。
Mermaid、数学公式等不提供图形或公式渲染；代码块显示原有代码内容。
表格每格适合一段文本；复杂嵌套内容、合并单元格和多段排版不能由普通 Markdown 表格完整表示。
外部修改了文件时，MD会阻止直接覆盖；请另存新文件保存编辑内容。
切换、新建与打开其他文档会保留原有修改。关闭标签时检查该标签；退出程序时检查所有标签，未保存修改会提示保存、放弃或取消。取消关闭、取消保存或保存失败会保留文档。
另存为的目标如果已在其他标签打开，会提示选择其他文件，避免覆盖另一份文档。
重启自动恢复标签、显示模式、缩放和阅读位置；原文件未保存的草稿从本机备份中恢复。仅命名还不等于保存，命名后的草稿仍需保存到磁盘。

源码开发
安装 Node.js 24 或符合依赖要求的版本，解压源码后运行 npm ci。
npm run build：生成界面资源。
npm start：启动开发应用（首次运行 Electron 包可能自动下载运行时）。
npm test：运行文件保护、编辑与图片路径测试。
npm run test:mindmap-features：验证连线说明、背景与样式、双击创建、取消/冲突保护、保存重开及草稿恢复。
npm run test:language：验证语言即时切换、重启记忆、编辑内容与位置保留、英文提示、模板和宽窄窗口。
npm run test:windows：验证窗口记忆、屏幕范围修正、外部文件打开队列与现有文档保留。
npm run test:windows-dpi：验证强制 100% / 125% / 150% / 200% 缩放下的界面与操作。
npm run test:recovery：验证异常退出后的 Markdown 草稿、无效 YAML、标签、位置与副本保护。
npm run test:recovery-map：验证导图草稿、颜色、连接、布局、缩放和位置恢复，包括后台标签备份。
npm run test:recovery-close：验证放弃、取消、关闭标签、外部修改保护和备份期间的前台操作。
npm run test:desktop：启动真实 Electron 窗口，使用测试文档检查主要交互与保存。
npm run test:code：检查实时高亮、语言选择、纯文本、保存重开、主题与语言控件布局。
npm run test:layout：检查宽窄窗口、目录展开及不同滚动位置下，格式栏不侵入正文区域。
npm run test:template：检查顶部模板按钮、新标签保留原文、关闭时保存/放弃/取消、取消保存、内置文件加载、另存完整模板和窄窗口布局。
npm run test:yaml：检查 SKILL 信息输入、完整文件头保留、直接保存、注释和未知字段、错误名称保护、重新打开、普通 YAML 和另存。
npm run test:position：检查阅读与编辑切换保持当前位置，覆盖长文中部/末尾、真实宽窄窗口、目录、反复快捷键、离屏代码光标与 SKILL 信息栏。
npm run test:tabs：检查多文档独立位置、正文、模式与撤销历史，重复打开、同名文件、关闭保存与取消、后台 SKILL 错误、另存冲突、退出输入保护、快捷键及窄窗口标签滚动。
npm run test:source：检查完整源码查看、源码/正文/对照切换、实时预览、BOM/CRLF 与原标记保存、源码撤销、正文撤销恢复原注释、跨模式副本保护、后台保存、另存图片路径、同步滚动、宽窄布局、黑色外观、SKILL 校验与退出输入冻结。
npm run package：打包 Windows x64 便携目录。源代码自带生成好的 icon.ico。
npm run test:zoom：检查真实 Ctrl+滚轮缩放、比例/范围/复原、普通滚动、三种模式、阅读与源码位置、横向长行、独立标签、另存为、窄窗口和文件未修改。
npm run test:compare：检查两侧编辑、双向同步、格式按钮、共享撤销/重做、跨模式撤销、延迟回包与本地图片、BOM/YAML保存、副本保护、位置、多标签、窄窗口、SKILL字段、Chromium模拟中文组字及退出冻结。
npm run test:naming：检查顶部命名与 F2、新草稿先命名和保存默认名称、已有文件改名、冲突保护、正文与历史保留、目录别名和窄窗口。
npm run test:mindmap：检查手工节点、关联文件与多标签位置、保存重开、另存链接、文件改名联动、历史、后台关闭保存、取消关闭、外部冲突和宽窄窗口。
npm run test:mindmap-open：检查真实双击打开、卡片空白区、阅读/编辑状态、未保存文档位置、文字编辑、连线与拖动保护。
npm run test:mindmap-style
npm run test:mindmap-interaction：检查节点/分支拖动、缩放换算、撤销与取消、位置保存重开、节点连接与删除、右键直接关联/打开文件及菜单边缘布局。
桌面测试仅使用源码目录 .desktop-test 下的文件，不使用真实工作文档。
